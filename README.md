# 轻映

轻量苹果 CMS V10 JSON 影视站。源配置保存在本地 JSON；默认列表、搜索和详情只访问所选源。搜索框的“全站”是主动选择的跨源搜索，结果标明来源。请只添加拥有使用授权的源及播放资源。

## 本地启动

需要 Node.js 22 和 npm。在项目根目录的 `.env` 中设置 `ADMIN_PASSWORD`，长度至少 12 个字符。服务启动时自动读取 `.env`；已设置的系统环境变量优先。服务在配置文件中保存密码的加盐 scrypt 哈希。修改 `.env` 中的密码并重启服务即可更新登录密码。

```powershell
npm ci
# 如果 .env 不存在，复制示例后编辑 ADMIN_PASSWORD
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
npm run build
$env:NODE_ENV = 'production'
npm run server
```

访问 http://localhost:8080，通过右上角“源管理”登录并添加 JSON 采集地址。保存后管理页面不会再次显示地址或密钥；编辑时地址留空表示保留原值，也可以输入完整新地址替换。测试连接前需先保存并启用源，然后选择编辑并点击“测试连接”；后端只接受源 ID。配置位于 `data/config.json`；请备份并限制读取权限，其中的源 URL 可能包含密钥。

开发模式：一个终端执行 `npm run server`，另一个终端执行 `npm run dev`，访问 Vite 显示的地址。Vite 将 `/api` 代理到 8080。`npm run build` 构建生产前端；`npm test` 执行测试。浏览器测试默认查找 Windows Chrome，可通过 `BROWSER_PATH` 指定 Chromium/Chrome 路径；找不到浏览器时该测试会跳过。浏览器测试需要先执行 `npm run build`。

登录源管理后可在“代理设置”中配置并启用 HTTP CONNECT 代理，例如 `http://127.0.0.1:7890`。代理仅用于后端请求影视源 API；海报和播放地址仍由浏览器直接访问。地址相对于后端运行环境，Docker 容器中的 `127.0.0.1` 指容器自身。代理配置保存在 `data/config.json`，可能包含认证信息，请限制文件访问权限。源域名仍由后端解析并进行公网地址检查。

## Docker

复制 `.env.example` 为 `.env`，设置强密码，执行 `docker compose up -d --build`，访问 `http://localhost:8082`。数据存放在 `cinema_data` 命名卷，重建容器不会丢失；删除卷会删除配置。正式环境通过 Nginx/Caddy 终止 HTTPS，设置 `COOKIE_SECURE=true`，代理应保留原始 Host 并正确配置外部 HTTPS 地址。请限制管理入口访问，并定期备份数据卷。

## 行为与限制

- 分类来自当前源的 `class`；“全部”不携带分类参数。无分类时仍加载列表；无可用源时不展示演示数据。
- 上游请求限制 DNS 和总请求时间、响应大小、并发及短期缓存；缓存按序列化数据大小最多保留 16 MiB、200 条，实际内存占用可能高于该数值。DNS 结果和每次重定向均检查特殊用途地址，解析结果固定用于连接。内网源不受支持；不提供绕过访问控制的播放代理。
- 浏览器直接访问海报和播放 URL；资源本身必须允许用户访问。HLS 需要浏览器原生支持或资源允许跨域，播放器仅识别 `.mp4` 和 `.m3u8` 地址。不保证第三方源格式或资源可用。
- 配置采用临时文件和重命名；只支持单进程写入，勿同时运行多个实例共用配置文件。登录会话、限流状态和缓存存于进程内，重启后清空。
- 本版使用 Vue、Vite、Fastify 和 hls.js；未使用 MySQL 或 Redis。具体测试与尚未执行的验收见 [验收记录](验收记录.md)。

## 上线步骤

1. 在具备 Docker 的 Linux 测试主机配置环境变量，构建镜像并运行测试端口；确认卷权限、健康检查、重启和备份恢复。
2. 添加已授权的两个真实源，验收动态分类、分页、搜索、详情和实际播放，并确认源地址与密钥未泄漏。
3. 由运维完成安全检查、HTTPS 反向代理及管理访问限制；仅在测试验收通过后切换正式入口。
